# PYOD Benchmark 

Here you can find all the files needed to benchmark confidence ensembles against PyOD algorithms.

The benchmark_plot.py script runs some of the algorithms that perform best in the PyOD benchmark, and uses them as base_estimator(s) for ConfBag and ConfBoost ensembles.

Results shown in the CSV file and in the PNG (both generated by the script above) show that COnfBag and ConfBoost ensembles are overall more time consuming than base estimators (expected), but also perform better in terms of AUC/ROC values. The scatterplot plots the rank of each algorithm (for each dataset, the best algorithm is rank 1, the second rank 2, and so on so forth) against time (train+test time) needed for classification. The lowest ranks are always achieved by confidence ensembles, showing a benefit for unsupervised binary classification overall.
